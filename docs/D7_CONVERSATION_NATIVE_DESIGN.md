## 一、背景（用户验收反馈，2026-09-13）

用户质疑：「为什么在企业端将讨论放到了协作这个功能里面，这个功能不应该直接在会话中吗，包括设计等内容。」——**两个方向都要**：

- **方向 A（去表单化）**：讨论/设计不该先填一张参数表单（模板/参与模型/裁判/轮次），应该在会话里自然发起
- **方向 B（去折叠化）**：讨论全文、设计/方案产出应该直接平铺在会话流里，而不是 200 字摘要 + 展开小窗

定位重申（09-08 D 系列定调）：**一个对话，背后是一支模型团队 + 共享知识库**。D1-D4 已把结果搬进会话；D7 消除剩余的「功能感」。

## 三、方案

### 3.1 方向 A：@ 提及自然发起（Q1/Q2）

**触发规则（Q1-A）**：企业模式下发送文本含 **≥2 个有效 @别名**（与参与模型清单匹配）→ 走协作；**恰好 1 个 @** → 该模型单聊（显式别名直通，GatewayRequest.alias 已支持）；**无 @** → 普通对话。别名不存在 → 系统提示「未找到模型 @X（可用：…）」，不发送。

**模板与轮次识别（Q2-A）**：从文本关键词映射——「辩论」→正反辩论、「评审」→方案评审、「头脑风暴」→发散头脑风暴、「收敛」→一致性收敛、默认「圆桌讨论」；「N轮」→轮次（1~10 钳制）。识别结果在提交提示中明示（可读性对账）。裁判：自然语言不指定 → 无裁判（composer 显式路径仍可选）。

**composer 去留（Q5-A）**：保留，默认收起（现状即收起，🧠 显式展开），作为显式参数控制路径；@ 路径完全不依赖它。🗂档案/📄草稿维持次级入口不变。

### 3.2 方向 B：内容全内联（Q3/Q4/Q6）

**讨论呈现（Q3-A + Q6-B）**：服务端新增**全轮次结构化存储** `transcript_data`（TEXT JSON：`{"rounds":[{"round":1,"texts":{别名:全文}}],"meta":{"mode","caption","winner","verdicts"}}`；CollabRun 新列，PG ddl-auto 自动迁移，旧 run 为 null 走兼容回退）；客户端按轮次平铺——每轮「━━ 第 N 轮 ━━」分隔 + 每模型色点气泡（**全文不截断**），裁判评语内联，首条分隔消息带模板/结束原因。旧 run（无 transcript_data）回退解析旧 `transcriptJson` 的 `◆ 别名：` 段（单层气泡）；再失败回退单系统气泡全文。不再 200 字摘要。

**执行/验收（Q4-A）**：③执行输出**不再 500 字截断**——全文气泡（ChatBubble 自动伸缩，超长靠滚动）；④验收理由维持全文。②结论本就全文不变。

**会话消息序列（改造后）**：
```
[用户气泡] @a @b 用辩论模式评审这个设计……
━━ ① 多模型讨论（正反辩论 · 2 模型 · 3 轮 · 裁判判定获胜方）━━
● a（色点头像气泡）：<末轮发言全文>
● b（色点头像气泡）：<末轮发言全文>
━━ ② 结论 ━━ <结论全文>
（B1 关：⏸ 暂停卡片 → ⚙ 执行并验收 / ▣ 就此打住）
━━ ③ 执行完成 ━━ <执行输出全文>
━━ ④ 验收：✅ 通过 ━━ <验收理由>
```

### 3.3 边界（不做的事）

- 不做 LLM 意图解析（纯规则，零成本零延迟）；不做会话中途切换参数
- 本批不动服务端（transcript 全轮次存储 = D7.2 另批）
- 普通对话、草稿关键词、档案行为全部不变

## 五、决策点（编号回复，A/B/C）

- **Q1** 触发规则：**A** ≥2 有效 @→协作、1 个 @→该模型单聊、无 @→普通对话（推荐）/ B 单 @ 报错要求 ≥2 / C 需显式「协作:」前缀 + @
  - **实施偏差**：服务端 ChatRequest 无逐请求模型字段，单 @ 指定模型单聊需服务端小改——本批降级为「单 @ → 提示需 ≥2 个 @」，指定模型单聊列为后续增项
- **Q2** 模板/轮次识别：**A** 关键词映射 + 「N轮」（推荐，识别结果提交提示明示）/ B 不识别统一圆桌单轮
- **Q3** 讨论呈现：**A** 每模型独立色点气泡 + 分隔消息（推荐）/ B 单气泡全文
- **Q4** 执行输出：**A** 全文内联不截断（推荐）/ B 超长折叠展开
- **Q5** composer 去留：**A** 保留收起为显式路径（推荐）/ B 彻底移除
- **Q6** transcript 数据源：**A** 解析现有末轮格式，失败回退（推荐，纯客户端）/ B 本批连服务端改全轮次存储（D7.2 范围扩大）
