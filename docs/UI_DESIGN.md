# OmniForge 视觉设计规范（v3，C-tier 批次 2 明暗主题）

> 落地载体：`omniforge-ui/src/main/resources/com/omniforge/ui/app.css`（暗色，令牌默认值）+ `app-light.css`（明亮，仅覆盖令牌）。
> 主题机制：所有颜色经 `.root` 的 `-of-*` 令牌（JavaFX looked-up colors）间接引用，切换 = 换样式表即时重解析；
> 主题偏好持久化于配置目录 `ui.yml`（ThemeManager + UiSettingsStore），导航栏 ☀️/🌙 按钮切换。

## 2. 字体

- 界面：`"Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", sans-serif`
- 技术信息：`"Cascadia Mono", Consolas, monospace`

## 3. 字号梯度

12px（标签/状态/辅助）· 13px（正文/气泡/按钮）· 14px（输入）· 16px（标题）

## 4. 圆角规范（P0 统一）

| 场景 | 圆角 |
|------|------|
| 按钮 | **8px** |
| 输入框/下拉 | **8px** |
| 卡片（配置卡片/步骤卡片） | **12px** |
| 气泡 | 12px |

## 5. 阴影

悬浮交互元素统一 `dropshadow(gaussian, rgba(0,0,0,0.35), 12, 0, 0, 4)`；背景层保持平坦。

## 6. 间距

4px 网格：4 / 8 / 10 / 12 / 14（卡片内边距 10-14，区块间距 8-10，页面边距 12-14）

## 7. 组件规范

- **顶部导航栏**：左侧 Logo（◆ 图形 + OmniForge 品牌名，14-16px 主色强调），右侧功能按钮（⚙ 配置）；无大字标题
- **Toast**：右上角浮层，绿（成功）/红（失败），3 秒自动消失，圆角 8，带阴影
- **步骤卡片**（思考→行动→观察）：独立卡片样式置入气泡流；三行结构——🧠 思考（模型文本摘要）、⚡ 行动（工具名+参数摘要）、👁 观察（结果摘要，等宽字体截断）；执行中为半透明/loading 态
- **空状态**：居中图标（🤖）+ 引导文案 + 次引导（"点击 ⚙ 配置 添加模型"）
- **聚焦态**：输入/按钮聚焦边框为主色 #2563EB

## 8. 气泡语义

用户右侧主色底 / AI 左侧卡片灰底 / 系统居中透明 muted / 错误红底红字 / 步骤卡片居中全宽卡片
